Tools

Tools I built while taking agents live, open source and free to use.

golive-gate

Turns agent eval cases, yes or no checks and a go-live rule into one command that answers go, partial or no-go, with the reason. Three files you can review: the cases, the checks as small Python functions, and the gate as YAML. A critical check blocks go-live on a single failure.

Several builds here run their gates on it, including the freight appointment agent, whose CI runs it before every rollout stage.

pip install golive-gate
